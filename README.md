# Objectives

Leverage Eurostat flax production data at NUTS2 data.

# Take-aways

1. France represents majority of production: biggest producing region is by far Haute-Normandie, followed by Nord-Pas-de-Calais, Picardie and Basse-Normandie.
2. There are some interesting inter-regional yield variability. Note that Eurostat yield is specific to the straw harvest, not the long fiber yield, that is the main output for the fiber flax industry.
3. Eurostat data can be used for some preliminary yield-analysis: the data is spatially coarse but probably sufficient to highlight environmental covariates of 
yield, and model price fluctuation for this niche crop market.
